# 后续优化

更新于 2026-09-15。验收证据、优先级与安全边界见 [验收计划](ACCEPTANCE-PLAN.md)。已实现不等于所有部署场景均已验收。

## 已实现

- Linux 指标采集、多服务器总览；30 分钟／1 小时／24 小时时间桶趋势，平均值和峰值，缺失段不补零。
- 指标、磁盘快照、告警事件统一到期清理，默认 7 天；启动及周期分批清理。
- SQLite 一致性备份、周期执行、份数保留和新路径恢复；已有独立恢复演练。
- 单管理员登录、8 小时会话、退出失效、写操作保护；一次性设备注册、ID 绑定、令牌摘要存储和撤销。
- 手动与可选定时扫描、展示深度及数量／软时间预算、不完整扫描保护、64 项分批遍历和条目速率节流。
- 目录增长事件持久化、分页历史与人工确认；确认不代表磁盘空间真实恢复。
- 测试机低权限 systemd 服务、异常重启、每日备份 timer、开机启用及 journald。
- 24 小时基础挂测通过。侧边栏及 HTTPS 代理场景的 `-secure-cookies` 配置已随新版 Hub 部署第一台测试机；侧边栏人工复验与真实 HTTPS 入口验收尚未完成，HTTP 预览未启用强制 Secure Cookie。

## 优先补齐

- 全天趋势后端及隔离数据库基础到期清理集成测试已通过；继续页面最终回归、安全回归、受控目录压力和 Agent 内存台阶增长原因观察。并发清理压力与周期长测仍未覆盖。
- HTTPS 证书与反向代理真实部署；专用测试机维护窗口内的整机重启验证。
- 通用安装前置检查、升级回滚／停用流程，以及最终版本备份恢复回归。

## 后期优化，不阻塞当前基础验收

- 自适应采样：区分本地检测与上报频率，保留最低检测频率，使用阈值和恢复迟滞，心跳与采样解耦。对比固定采样的 CPU、网络、存储开销和异常捕获率后再推广。
- 长期历史预聚合与分层保留；现有趋势查询聚合不等于存储降采样。
- 备份状态面板、加密／异地备份、大数据库增量备份。
- 扫描跨挂载点策略、硬链接去重、物理块统计、系统级 IO 优先级；当前统计逻辑大小、硬链接按路径计数，不跟随符号链接。条目节流不等于磁盘 MB/s 硬限速，软时间预算不保证硬实时终止。
- 设备分组／删除、多用户和角色权限、凭据恢复、操作人审计、外部通知和真实恢复判定。

第二台 wsrser 的现有业务优先；不自动常驻部署、重启、断网或扫描业务目录。需要外部维护窗口的验收交由用户安排。
