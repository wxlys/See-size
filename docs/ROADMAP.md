# 后续优化

- 历史保留期限：可配置 1 天、7 天等；分批清理到期记录，结合降采样保留长期趋势。现阶段尚未自动删除历史。
- SQLite 一致性备份：独立配置备份周期、保留数量与恢复验证；使用在线备份机制，避免运行中只复制主数据库遗漏 WAL 数据。备份不能替代过期清理。
- 磁盘快照同样需设置保留期限。
- 磁盘分析第一阶段：显式指定目录、单次扫描、展示深度、时间与数量预算、快照比较。当前仅统计逻辑文件大小，不等于物理磁盘占用；硬链接按路径重复计数，不跟随符号链接，非完整扫描不生成增量结论。
- 后续扫描优化：跨挂载点策略、硬链接去重、物理块统计、分批遍历与 IO 限速、定时扫描及异常阈值。当前目录遍历和内核文件操作可能超过软时间预算，不提供硬实时保证。
- 设备独立凭据、用户登录后，再开放远程管理操作。
