# 后续优化

- 已完成：历史指标和磁盘快照统一按保留天数清理，默认 7 天；启动时及每 10 分钟分批清理。长期趋势降采样待实现。
- SQLite 一致性备份：独立配置备份周期、保留数量与恢复验证；使用在线备份机制，避免运行中只复制主数据库遗漏 WAL 数据。备份不能替代过期清理。
- 自适应采样（后期）：稳定时降低采样频率，资源突增时提高频率；区分本地检测频率与上报频率，保留最低检测频率、触发阈值和恢复迟滞，避免漏掉短峰值或频繁切换。在线心跳与采样解耦；曲线需按实际时间绘制并保留峰值。需对比固定采样的 CPU、网络、存储开销和异常捕获率。
- 磁盘分析第一阶段：显式指定目录、单次扫描、展示深度、时间与数量预算、快照比较。当前仅统计逻辑文件大小，不等于物理磁盘占用；硬链接按路径重复计数，不跟随符号链接，非完整扫描不生成增量结论。
- 后续扫描优化：跨挂载点策略、硬链接去重、物理块统计、分批遍历与 IO 限速、定时扫描及异常阈值。当前目录遍历和内核文件操作可能超过软时间预算，不提供硬实时保证。
- 设备独立凭据、用户登录后，再开放远程管理操作。
- 已完成定时扫描第一版：Agent 可配置单目录周期扫描，任务不重叠，独立于心跳；Hub 按两次完整扫描净增量阈值提示。下一步：独立告警事件存档、恢复／确认状态、全局提示汇总与扫描 IO 限速。当前提示仅针对最近两次扫描。
