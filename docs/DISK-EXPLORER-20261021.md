# 目录分析可用性改进（2026-10-21）

后续状态：用户授权后于当日部署到 wsrser；验证与实际数据边界见 [上线记录](DISK-DEPLOYMENT-20261021.md)。以下本地实现阶段描述保留原始时点。

范围：目录大小／增量排序、占比条、折叠展开、扫描结果原因，以及不完整扫描的完整结果参考。当前为本地实现与隔离验收，尚未部署线上。

## 使用行为

- 默认按同级目录占用从大到小排列，可切换为增长量从大到小；保留父子层级，不把父目录与子目录放在同一排行中相加。
- 占比与横条以所展示结果的根目录大小为分母。父目录包含子目录，不能将所有行占比相加。
- 默认展开根目录，其余分支可折叠、展开。增量比较中消失的目录标记为“已移除”，保留负增量。
- 每次先渲染最多 500 个可见目录，可手动显示更多。自动刷新保留同一服务器／根目录／深度的排序、展开和结果来源选择；数据未改变时不替换 DOM。
- 展示最近扫描时间、完整性和条目情况；条目上限、软超时或取消、不可读取或排除分别提供中文原因。本轮没有新增扫描进行中的进度上报，也不从网页发起扫描。

## 完整结果参考

当最新快照不完整时，接口额外提供此前同设备、同根目录、同展示深度的最近完整快照（若仍保留）。即使连续多次扫描不完整，也可查询到这份参考。

页面默认展示带原始时间的“上次完整结果（参考）”，明确不代表当前占用；也可切换为“本次部分结果”。两种查看方式都不计算本次增量，不启用增长排序，不生成本次增长告警。完整快照只用于查看，不作为绕过不完整检查的比较基线。

没有新增扫描任务、快照副本或永久保留项。参考仍由已有历史保留策略清理；清理后显示本次部分结果并保持不可比较。相邻完整快照之间的比较和告警算法未改变。
