## 定位与范围

面向个人开发者和小型服务器集群的 Linux 资源监控与目录空间变化定位工具。轻量 Agent 主动上报，Hub 提供 Web 面板和 SQLite 历史存储。Agent 是采集程序，不是大模型智能体。

主要解决多主机分散查看、短时曲线不足以追溯、目录空间增长难以定位、历史和备份缺少生命周期管理。差异化是将资源趋势、受控目录扫描、变化事件与可持续维护结合；不宣称多服务器监控是行业首创或已具备自动根因诊断。

交付包含源码、已有立项与概要需求文件、维护手册、测试脚本、验收记录及已部署服务。论文、答辩幻灯片、通用安装器、原生桌面客户端不包含在本次完成声明中。早期 Word 文档本轮未改写，后续修订需对齐本交付范围。

## 可持续性说明

- 指标、目录快照、事件默认七天，启动及每十分钟分批清理。不是到期瞬间删除，积压受清理预算影响。
- 每日约 03:00 后备份，成功验证后保留最近七份；手动备份也计入。每份是当时全库快照，不是仅最近 24 小时；七份不严格等于七个日历日。
- 登记的升级回退点保留最新三个，约 04:00 后维护清理到期登记产物，定时器带随机延迟。
- SQLite 复用空闲页，文件不一定缩小。设备数、频率、扫描规模增加会提高容量，不承诺总占用永远不变。
- 未登记目录、安全身份标记、共享 journald、本地缓存与实验资料不由上述期限一概清除。容量告警不是硬配额，也无外部推送。

详细规则见 [存储生命周期](STORAGE-LIFECYCLE.md)。线上维护脚本尚未部署新版共享锁，手动升级仍需协调定时器。
