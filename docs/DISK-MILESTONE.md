# 磁盘分析第一阶段验证

验证日期：2026-09-13。

实现：独立的一次性扫描程序，显式选择根目录，默认展示深度 3、最多 20000 个条目、软时间预算 15 秒。常驻 Agent 无需开启扫描。快照独立上报至 Hub，保存到 SQLite，页面可查看目录层级和两次完整扫描之间的大小变化。

本地验证：扫描深度不影响深层文件累计；文件增加反映到父目录；数量限制和取消产生部分结果；部分结果禁止比较；上传必须认证；快照在数据库重新打开后仍可比较。Go 测试与静态检查通过，页面脚本语法检查通过。

Linux 实机验证：在独立测试目录进行第一次空目录扫描，随后加入 1003 字节文件并再次扫描。接口返回根目录和 docs 子目录均增加 1003 字节，两个快照均完整。已部署新 Hub 与扫描程序；没有为目录分析开放公网端口。

当前限制：比较结果表示两次扫描之间的净变化，不能证明增长发生的具体时刻或进程；尚未实现增长告警。逻辑大小不等于物理磁盘空间；跳过符号链接和不可读项时结果不完整。页面最多展示 500 个目录。页面未做自动化浏览器交互验收，后续需补齐。数据及备份保留策略见 ROADMAP.md。
