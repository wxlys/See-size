# 下载预算与校验缓存（2026-10-01）

仅修改安装工具源码，尚未发布新版本，不覆盖 rc.2/rc.3 附件。Hub 与 Agent 采集程序无需更新。

## 使用方式（新版工具）

```sh
sudo python3 agent-setup.py update --version <已发布目标版本> --download-timeout 1800
```

预算允许 30～3600 秒，默认 180 秒，按每个 HTTPS 资源计，包含重试等待。每次网络操作超时仍为 15 秒，最多三次尝试。延长预算不会修复网络连接重置。

## 缓存边界

- 固定目录 `/var/cache/seesize-agent-downloads`，root 所有、权限 700；已有不安全目录或未知文件会拒绝使用，要求人工检查，不递归删除。
- 只缓存完整、ELF 架构及 SHA256 校验通过的 Agent/enroll 文件；清单每次重新获取。缓存命中须重新与此次清单哈希比对，版本不同但二进制相同可以复用。
- 每个组件仅一个槽位，持久缓存最多 128 MiB（两个组件各上限 64 MiB）；原子写入临时文件时最多额外 64 MiB。安装 staging、已安装程序和 rollback 不计入这个缓存上限。
- 写入后超过七天的缓存，在下一次联网安装/更新进入程序获取阶段清理；不是定时删除。停用时文件不会自行消失，但数量和大小有界。命中不延长写入时间。
- 残缺临时文件下次使用时清理；未通过校验的下载不保存。坏缓存删除后重新下载。没有断点续传。
- 修改动作沿用安装器互斥锁；check-update 不建立或清理缓存，--bundle 不使用缓存。失败退出不会删除有效设备凭据。
