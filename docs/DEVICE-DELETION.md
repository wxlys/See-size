# 设备删除与历史清理

“撤销凭据”禁止继续上报但保留卡片及历史。“删除设备及历史”只对已撤销设备开放，须输入完整设备 ID 确认。请先自行停止对应 Agent，Hub 删除操作不会卸载远端程序。

接口 `DELETE /api/v1/devices/{agentID}`，登录会话、写请求保护头和 JSON `{"confirm_id":"对应ID"}` 均必需。未撤销返回 409，确认错误 400，目标不存在或已删除 404。凭据记录和删除标记保留为内部拒绝旧凭据的记录，不显示在列表；指标、目录快照、告警、待兑换注册码和服务器卡片在一个事务内删除。

删除是在线数据库的逻辑清理，不自动压缩 SQLite 文件，也不擦除磁盘残留。不删除已有备份、归档或本地报告；从旧备份恢复会恢复其当时的设备状态，须重新核对授权。用户主动生成新注册码并兑换后可以重新使用相同 ID，但不会恢复被删除的历史。

删除标记防止已通过认证但尚未写入的请求在删除后重建数据。共享旧凭据仍受保留的 revoked 记录阻止。该标记不随历史保留期限自动清理。

新增 deleted_devices 表；升级时自动创建。回退到不认识删除标记的旧版可能重新展示内部保留的 revoked 记录，故删除功能启用后不可将旧版回退视为完整语义兼容。

验证使用临时数据库和浏览器模拟设备，未删除真实 wsrser-main。Go 回归覆盖未登录、写保护、确认不符、未撤销、重复删除、其他设备保留、迟到写入拒绝及显式重新注册。浏览器脚本 scripts/browser-device-delete-check.cjs 验证取消、输错、成功提交与列表刷新。
