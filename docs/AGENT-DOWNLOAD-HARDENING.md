# 安装器下载反馈改进（2026-09-30）

范围仅 scripts/agent-setup.py，不改变采集程序、Hub、协议或线上服务。已发布 rc.2 附件保持原样；以下改进尚未打包发布，不能认为下载 rc.2 已包含这些功能。

- 分块读取，每约两秒有新数据时显示已下载字节、总字节（若已知）及平均速度；连接阶段立即显示尝试次数。
- 每个资源在 Linux 主线程下使用 180 秒总预算，覆盖连接、读取、重试等待；每次网络操作超时 15 秒。总预算不是整个多文件安装的总预算。
- 临时网络错误及 HTTP 408/429/500/502/503/504 最多三次尝试，间隔两秒，从零重新下载，不拼接残缺文件。
- 404、证书校验失败、大小超限不重试；保留 HTTPS、禁止降级和后续 SHA256 校验。
- Ctrl+C 给出简明取消说明；下载发生在更新停止服务之前。替换阶段的回退机制不变。
- 不输出完整请求/重定向 URL 或原始网络异常，避免带出查询参数。

这不能修复网络路径上的连接重置，只使失败可见且等待有界。未增加第三方镜像或跳过 TLS。

验证：Windows 15 项通过、Linux 专属计时器测试跳过；本地 Ubuntu 虚拟机 16 项全部通过，包括真实计时器打断阻塞等待。网络重置、残缺下载、404、超限、取消通过模拟响应测试；不将其当作虚拟机到 GitHub 的真实网络恢复证明。实验只运行独立目录下的测试脚本，没有替换已安装程序或重启服务。
